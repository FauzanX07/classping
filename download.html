Class Ping in your browser

Nothing to install. Sign in with Google and use it on any computer or phone. Read-only, and everything stays in your browser. It only notifies you while the page is open; for alerts all day, use the Windows app.

Open the web app

What you need

System
Windows 10 or 11, for the Windows app
Browser
Any current web browser, for the web version
Account
A Google Classroom account

How to get it

  1. Download it. Press Download for Windows. A small installer opens the Microsoft Store and installs Class Ping. You can also open the Store, search for Class Ping and click Get.
  2. Sign in with Google. Approve Class Ping on Google's own screen. You never type your password into Class Ping. For comments and attachments inside the app, turn on Full features in Settings.
  3. That is it. Your posts appear, sorted into To-Do and the other sections, and Class Ping pings you when a teacher posts something new.
