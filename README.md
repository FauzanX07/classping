# Class Ping website

This repository holds the website for **Class Ping**, a free Windows app for students.
Class Ping shows your Google Classroom posts sorted into a to-do list, and notifies you
when a teacher posts something new.

**Live site:** https://classping.wazeem.com

- [Home page](https://classping.wazeem.com)
- [Privacy policy](https://classping.wazeem.com/privacy.html)

## What is here

| File | What it is |
|---|---|
| `index.html` | The home page |
| `privacy.html` | The privacy policy |
| `style.css` | The look of both pages |
| `CNAME` | Points the site at classping.wazeem.com |
| `logo.png`, `favicon.png`, `apple-touch-icon.png` | The Class Ping logo |

The Class Ping app itself is not in this repository.
